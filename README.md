# Travel Ledger

一个只保留记账功能的静态网页。

## 数据存储

账单默认只保存在当前浏览器的 localStorage 中，不会提交到 GitHub。

换网址或换设备时：

1. 旧网址：设置 → 账本备份 → 导出账本
2. 新网址：设置 → 账本备份 → 导入账本

## GitHub Pages

仓库为 Public 后，可在 Settings → Pages 中选择：

- Source: Deploy from a branch
- Branch: main
- Folder: /(root)
